# Riso Club — a cut-and-paste zine press

A small print shop in a browser tab. Type a cover line, pick a composition and an ink pairing, rewrite any page, then preview and print the whole thing. Every page is built from type, halftone dots and overprinted CSS shapes — no images, no assets, no press operator.

The look is a fluorescent two-drum photocopier on cheap cream stock: pink and blue inks that never quite line up, crop marks, staples, a barcode and a lot of paper texture.

## Features

- Live A5 zine page on a gridded press bed, with crop marks and staples.
- Cover title and subtitle edited either in the press controls or directly on the page.
- Four compositions: Cut & paste, Halftone halo, Column riot and Big type.
- Four ink pairings: Pink over blue, Blue over pink, Pink only and Blue only.
- Page count from 4 to 12 pages, cover included.
- Misregistration slider from sharp to sloppy, shifting the second ink under the type.
- Click any page kicker, heading or paragraph to rewrite it. Nine interior pages arrive with small essays, lists, recipes and field notes; all edits persist.
- Page flipper with previous/next buttons, arrow-key support and a thumbnail strip.
- Print preview showing every page flat, with focus trapping, Escape to close and a print button.
- Real print output: each page is placed on its own A4 sheet at A5 size, with crop marks, ready to fold and staple.
- Title, subtitle, layout, ink, page count, misregistration, current page and all page edits survive a page reload in `localStorage`.
- Keyboard-friendly controls, visible focus, `aria-pressed` states, a skip link and a live status region.
- Responsive down to 390px with no horizontal overflow, plus a reduced-motion mode.

## Running it

No build step, package manager, framework or dependencies. Open `index.html` directly in a browser, or serve the folder as static files. The only network request is Google Fonts; all artwork, texture and ink is generated by CSS and the page itself.

## Files

- `index.html` — masthead, press controls, page bed, thumbnail strip, preview overlay and print root
- `styles.css` — newsprint palette, zine page templates, cover art, controls, print rules and responsive layout
- `app.js` — page generation, inline editing, navigation, ink and composition state, preview, printing and persistence
- `README.md` — this document
